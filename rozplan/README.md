# Roz ka Plan (Android)

Native Android port of the "Roz ka Plan" web page: daily timetable (ring + tick list, habits, water), meal planner with kcal/protein totals, animated home workout (stick figures + timer + YouTube links), weight progress (stats, chart, 14-day dots, log). PIN login (4 digits, create on first launch). Light/dark follows the phone. Designed and Developed by IronicXsoft.
- Android 6.0+. Build: `python3 tools/build_apk.py` (needs android-all.jar + dx.jar); UI snapshot tests: `tools/rt`.
